# Triage Labels

This repo does not use the Matt Pocock skills triage-label workflow.

Do not create or apply triage labels unless the user explicitly asks to use triage labels for a task.

If triage labels are introduced later, map these canonical roles to the repo's actual labels:

| Canonical role | Repo label |
|---|---|
| `needs-triage` | not configured |
| `needs-info` | not configured |
| `ready-for-agent` | not configured |
| `ready-for-human` | not configured |
| `wontfix` | not configured |
